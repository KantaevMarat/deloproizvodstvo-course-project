# Делопроизводство
Учебный локальный прототип по варианту К–Л. Автор: Кантаев Марат Эльбрусович.

## Запуск
Python 3.10 или новее, внешние библиотеки не требуются.
Из папки проекта: `python app.py`, затем откройте http://127.0.0.1:8765.
Остановка: Ctrl+C. База documents.sqlite3 создается автоматически с тремя учебными записями.
Проверки: `python -m unittest discover -s tests -v`.

## Возможности
Регистрация входящих, исходящих и внутренних документов; поиск по теме; последовательные переходы Новый → В работе → Исполнен; журнал изменений в SQLite. Данные сохраняются после перезапуска.

## Границы прототипа
Только локальная работа на 127.0.0.1. Нет авторизации, разграничения доступа и загрузки вложений. Роли описаны в проектной документации как требования будущей версии, а не как реализованная защита. Не предназначен для публикации в Интернете.

## Управление версиями
Основная ветка main. Ветки этапов: lifecycle/requirements, lifecycle/design, lifecycle/implementation, lifecycle/testing, lifecycle/release.
Публичный репозиторий: https://github.com/KantaevMarat/deloproizvodstvo-course-project
История публикации в GitHub организована по этапам: требования, проектирование, реализация, проверка и выпуск. Исходный локальный учебный репозиторий имеет отдельную историю демонстрации команд Git.
