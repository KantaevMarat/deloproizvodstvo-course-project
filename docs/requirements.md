# Требования и критерии приемки
Назначение: учет регистрации и исполнения документов небольшой организации.
Пользователи будущей версии: секретарь регистрирует, руководитель назначает исполнителя, исполнитель работает со своими поручениями, администратор управляет учетными записями.
FR1: создание карточки с темой, видом, корреспондентом, исполнителем и сроком.
FR2: поиск по теме. Текущий SQLite-прототип чувствителен к регистру кириллицы; это ограничение необходимо снять перед промышленной приемкой.
FR3: переходы Новый → В работе → Исполнен без пропуска этапов.
FR4: журнал каждого изменения.
FR5: сохранение после перезапуска.
Приемка прототипа: 7 автоматических тестов; ручная регистрация и смена статуса в браузере.
Не входит: ЭЦП, OCR, интеграция почты, вложения, многопользовательская авторизация.
