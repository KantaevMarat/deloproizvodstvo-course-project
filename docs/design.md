# Архитектура
Браузер → HTTPServer (127.0.0.1) → прикладные функции → SQLite.
Таблица documents: id, title, correspondent, kind, assignee, deadline, status.
Таблица history: id, document_id, event, created_at.
Вставки и изменения выполняются в транзакции, запросы параметризованы.
HTML экранируется при выводе. Прототип не имеет авторизации, поэтому доступ к сетевому интерфейсу ограничен loopback.
Для полноценной системы нужны роли, проверка прав на сервере, резервирование БД, миграции, отдельная СУБД и промышленный сервер.
